# Mona Crossing

Hop across endless roads and rivers one tile at a time without getting flattened, drowned or left behind.

Dodge cars and trucks, ride the logs, weave between the trees, and keep
moving: the screen creeps forward and dawdling ends the run. Every row
forward is a point; the badge keeps your best.

## Controls

* Up / Down / Left / Right: hop one tile
* Select: start; hop again after a splat
* Back: back to the title

## Requirements

No network. Best run and run count are saved under `/state`. The sprites in
`assets/` are drawn by the repository's `tools/build_sprites.py`.
